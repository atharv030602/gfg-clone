## 💻 **Local Development**

### **Quick Start**
```bash
# Clone the repository
git clone https://github.com/atharv030602/gfg-clone.git
cd gfg-clone

# Open with live server (recommended)
npx live-server
# OR
python -m http.server 8000
```

### **Direct File Access**
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```
